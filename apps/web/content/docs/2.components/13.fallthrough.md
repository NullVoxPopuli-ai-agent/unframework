title: Fallthrough
description: Attributes, DOM listeners, class and style a component doesn't declare fall through to its root element, or to the element its rest is spread on.
navigation:
  icon: i-lucide-arrow-down-to-line
---

A parent often needs to reach the element inside a component it doesn't own: give a button an `id` that a label points at, describe it with `aria-describedby`, tag it for a test, listen to its `focus` or give it some margin. So what a parent passes a component, and the component doesn't declare, falls through to the component's root element. It's Vue's rule, and every target follows it.

This page walks you through it. We'll look at:

- the attributes that fall through, and the ones that don't
- the DOM listeners that fall through
- `class` and `style`, which merge with the root's own
- a component whose root is another component
- a ref on a component that exposes nothing
- `...rest`, which puts all of it on another element
- turning fallthrough off, and the components that can't take it

## What falls through

Let's start with the rule. A component declares its props, its models, its slots and the events it lists in `defineEmits`. Everything else a parent passes it falls through:

- **Attributes**, like `id`, `aria-*`, `data-*` or `type`, land on its root element.
- **Listeners** of DOM events, like `onClick` or `onFocus`, listen on its root element.
- **`class` and `style`** merge with the root element's own.

The root element is the one element the component renders at its top. A root that is a component passes all of it on to that component, which places it by the same rule.

A declared prop never falls through, so a prop named like an attribute stays a prop. Where the root element sets an attribute the parent passes too, the parent's value wins. `key` is no attribute, and a `ref` holds the root element ([Refs](#refs)).

## Attributes

Here a parent passes a button an `id`, two ARIA attributes, a test id and a `type`. The button declares only `title`:

<!-- prettier-ignore -->
```tsx [SaveButton.uf.tsx]
// Declares one prop, `title`, which it renders as text: a declared prop never falls through.
export default function SaveButton({ title }: { title: string }) {
  return (
    <button type="button" class="button">
      {title}
    </button>
  );
}
```

```tsx [Editor.uf.tsx]
      </button>

```

`title` is a prop `SaveButton` declares and renders as text, so it never reaches the `<button>` as an attribute. Everything else lands on the `<button>`: the `id`, the ARIA attributes, the `data-testid` and the `type`, where the parent's `submit` wins over the button's own `button`. The bound `aria-pressed` follows `pressed` as it changes. The corpus records the rendered DOM this way, with each text node in quotes:

<!-- prettier-ignore -->
```html
<div class="editor">
  <p id="save-hint">
    "Saves the draft."
  </p>
  <button aria-describedby="save-hint" aria-pressed="false" class="button primary" data-testid="save-button" id="save" type="submit">
    "Save"
  </button>
  <button type="button">
    "Toggle"
  </button>
</div>
```

The parent checks each attribute as one of that element's own, so the element's rules hold: HTML's names, the values an enumerated attribute allows and ARIA's ([Attributes](/docs/components/attributes)). A name that is no prop of the child and no attribute of its root element is [UF3035](/docs/reference/diagnostics#UF3035), with a fix to the closest prop.

```tsx [SaveButton.tsx]
function cx(...parts: unknown[]): string {
  const names: string[] = [];
  for (const part of parts) {
    if (typeof part === "string") {
      if (part) names.push(part);
    } else if (part && typeof part === "object") {
      for (const [key, on] of Object.entries(part)) {
        if (on) names.push(key);
      }
    }
  }
  return names.join(" ");
}
```

```ts [save-button.ts]
import { isPlatformBrowser } from "@angular/common";
import {
  Component,
  Directive,
  ElementRef,
  type OnChanges,
  type OnDestroy,
  type OnInit,
  PLATFORM_ID,
  Renderer2,
  inject,
  input,
  viewChild,
} from "@angular/core";

/** The scope attributes taken off each host, for the roots its component renders later. */
const scopes = new WeakMap<Element, string[]>();

/**
 * Gives a root node of its component the scope attributes the component's styled parents put on
 * its host (ADR-0063), and takes them off the host, which keeps only `display: contents`.
 */
@Directive({ selector: "[ufScope]" })
export class ScopeAttributes implements OnInit {
  readonly ufScope = input.required<HTMLElement>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);

  ngOnInit(): void {
    const host = this.ufScope();
    let names = scopes.get(host);
    if (!names) {
      names = host.getAttributeNames().filter((name) => name.startsWith("data-uf-"));
      for (const name of names) this.renderer.removeAttribute(host, name);
      scopes.set(host, names);
    }
    for (const name of names) this.renderer.setAttribute(this.element.nativeElement, name, "");
  }
}

/** A native listener of each event a consumer passes, by the event's name (ADR-0118). */
type Listeners = { [K in keyof HTMLElementEventMap]?: (event: HTMLElementEventMap[K]) => void };

/**
 * Puts what a consumer passes the component, and the component does not declare, on the element
 * that takes it (ADR-0118): the attributes, the consumer's winning over the element's own, and
 * the native listeners, which run after the element's own.
 */
@Directive({ selector: "[ufFallthrough]" })
export class Fallthrough implements OnChanges, OnDestroy {
  readonly ufFallthrough = input.required<{
    attributes: Record<string, unknown> | undefined;
    listeners: Listeners | undefined;
  }>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);
  private readonly browser = isPlatformBrowser(inject(PLATFORM_ID));
  private readonly listening = new Map<string, { handler: unknown; stop: () => void }>();
  private written: Record<string, unknown> = {};

  ngOnChanges(): void {
    const element = this.element.nativeElement;
    const { attributes = {}, listeners = {} } = this.ufFallthrough();
    for (const name of Object.keys(this.written)) {
      if (!(name in attributes)) this.renderer.removeAttribute(element, name);
    }
    for (const [name, value] of Object.entries(attributes)) {
      if (value === null || value === undefined) this.renderer.removeAttribute(element, name);
      else this.renderer.setAttribute(element, name, String(value));
    }
    this.written = attributes;
    if (!this.browser) return;
    const handlers = new Map(Object.entries(listeners));
    for (const [event, { handler, stop }] of this.listening) {
      if (handlers.get(event) === handler) continue;
      stop();
      this.listening.delete(event);
    }
    for (const [event, handler] of handlers) {
      if (handler === undefined || this.listening.has(event)) continue;
      this.listening.set(event, { handler, stop: this.renderer.listen(element, event, handler) });
    }
  }

  ngOnDestroy(): void {
    for (const { stop } of this.listening.values()) stop();
  }
}

@Component({
  selector: "uf-save-button",
  imports: [ScopeAttributes, Fallthrough],
  host: { "[attr.class]": "null", "[attr.style]": "'display: contents;'" },
  preserveWhitespaces: false,
  template: `
    @let title = this.title();
    <button
      type="button"
      class="button"
      [class]="this.class()"
      [style]="this.style()"
      [ufFallthrough]="{ attributes: this.ufAttributes(), listeners: this.ufListeners() }"
      [ufScope]="this.host"
      #ufElement
    >{{ title }}</button>
  `,
})
export default class SaveButton {
  readonly title = input.required<string>();
  readonly class = input<string>();
  readonly style = input<Record<string, string | null | undefined>>();
  readonly ufAttributes = input<Record<string, unknown>>();
  readonly ufListeners = input<Listeners>();
  readonly ufElement = viewChild<ElementRef<HTMLButtonElement>>("ufElement");
  protected readonly host = inject<ElementRef<HTMLElement>>(ElementRef).nativeElement;
}
```

::

- React types what falls through as the root element's own props without the declared ones, `SaveButtonAttributes`, and the root spreads the props' rest, `{...attributes}`, after its own attributes, so the parent's win. A parent writes them in React's spelling for that element, like `className` or `tabIndex`.
- Vue passes them on by itself, as its own `$attrs`.
- Svelte types the props with the root element's attributes from `svelte/elements`, without the component's own names, and the root spreads the props' rest, `{...attributes}`, last.
- Angular has no attribute spread, and a host element that carries an attribute isn't unwrapped ([The Angular host](/docs/reference/targets#the-angular-host)). So each component declares two more inputs: `ufAttributes`, a record of attributes by name, and `ufListeners`, a record of listeners by event. The parent binds them on the host, `[ufAttributes]="{ id: 'save', … }"`, which keeps no attribute. The root binds an inline attribute directive, `Fallthrough` (`[ufFallthrough]`), which sets and removes the attributes through `Renderer2`, on the server and in the browser, the parent's winning ([`fallthrough`](/docs/reference/targets#capabilities), emulated). A hand-written Angular parent that writes `id="save"` on `<uf-save-button>` puts it on the host, so it binds `[ufAttributes]="{ id: 'save' }"` instead.
- Solid takes the declared props out with `splitProps`, and the root spreads the others after its own attributes, so the parent's win.
- Qwik types the props with the root element's own, `Omit<PropsOf<"button">, …>`, and the root spreads the props' rest last.
- Astro spreads the rest of `Astro.props` last on the root. Astro writes every attribute it is given and the browser [keeps the first of two](https://html.spec.whatwg.org/multipage/parsing.html#parse-error-duplicate-attribute), so the root reads each of its own attributes from the props first, `type = "button"`, and the parent's value wins. Keep in mind that an `undefined` the parent passes keeps the root's value there, where Vue removes the attribute.

So every output but Vue's types and spreads what falls through on each component with one root element, and you'll see it on every page of these docs, even where no parent passes anything. The rest the root spreads also carries a styled parent's `data-uf-*` scope attribute, so the parent's stylesheet reaches the root ([Styles](/docs/components/styles#the-childs-root)).

## Listeners

```tsx [Picker.uf.tsx]
      </ol>

```

Where the root listens to the same event itself, both run, the root's own first, as Vue merges them. So tab to the chip, press `a` and click it, and the log reads "focus", "keydown a", "pick Ada" and "click".

An `onX` that is neither an event the child declares nor a DOM event is [UF3036](/docs/reference/diagnostics#UF3036), with a fix to the closest event. A listener option on a listener that falls through, like `onClickOnce`, is [UF1002](/docs/reference/diagnostics#UF1002).

```ts [chip.ts]
    this.written = attributes;
```

- React takes the parent's `onClick` out of the props' rest and calls it from the root's own handler, after it emits `pick`. React's `onFocus` also hears focus that moves inside an element, so the parent's React output checks `event.target` to keep the DOM's `focus`. A listener whose React prop wouldn't keep the DOM's meaning on that element is [UF1002](/docs/reference/diagnostics#UF1002) on React: `change` on a text field, `focusin`, `focusout`, `select` and `beforeinput`.
- Vue merges the parent's listener with the root's own by itself.
- Svelte takes `onclick` out of the props' rest and calls it from the root's own handler, after its own code.
- Angular's parent binds `[ufListeners]="{ click: …, focus: …, keydown: … }"` on the host, and `Fallthrough` adds each listener with `Renderer2.listen` in the browser, after the element's own.
- Solid takes `onClick` out with `splitProps` and calls it from the root's own handler, after its own code.
- Qwik passes the root an array of both, `onClick$={[$(() => onPick$?.(label)), onClick$]}`, which runs the root's own first.
- Astro renders on the server only, so no listener runs: the output drops it, and the compiler reports it for information ([`interactivity`](/docs/reference/targets#capabilities)).

```svelte [Tag.svelte]
  type Props = Omit<
    SvelteHTMLElements["span"],
    "label" | "children" | "class" | "style" | "ref"

  function mergeStyle(
    own: Record<string, string | number | null | undefined>,
    consumer: string | undefined,
  ): string {
    const merged = { ...own };
    const text = consumer ?? "";
    const add = (declaration: string) => {
      const colon = declaration.indexOf(":");
      if (colon > 0)
        merged[declaration.slice(0, colon).trim()] = declaration.slice(colon + 1).trim();
    };
    let start = 0;
    let depth = 0;
    let quote = "";
    for (let index = 0; index < text.length; index++) {
      const char = text[index];
      if (quote) {
        if (char === "\\") index++;
        else if (char === quote) quote = "";
      } else if (char === "\\") index++;
      else if (char === "/" && text[index + 1] === "*") {
        const close = text.indexOf("*/", index + 2);
        index = close === -1 ? text.length : close + 1;
      } else if (char === '"' || char === "'") quote = char;
      else if (char === "(") depth++;
      else if (char === ")") depth--;
      else if (char === ";" && depth === 0) {
        add(text.slice(start, index));
        start = index + 1;
      }
    }
    add(text.slice(start));
    return Object.entries(merged)
      .map(([property, value]) => `${property}: ${value ?? ""}`)
      .join("; ");
  }
```

```ts [tag.ts]
    for (const name of names) this.renderer.setAttribute(this.element.nativeElement, name, "");
  }
}

/** A native listener of each event a consumer passes, by the event's name (ADR-0118). */
type Listeners = { [K in keyof HTMLElementEventMap]?: (event: HTMLElementEventMap[K]) => void };

/**
 * Puts what a consumer passes the component, and the component does not declare, on the element
 * that takes it (ADR-0118): the attributes, the consumer's winning over the element's own, and
 * the native listeners, which run after the element's own.
 */
@Directive({ selector: "[ufFallthrough]" })
export class Fallthrough implements OnChanges, OnDestroy {
  readonly ufFallthrough = input.required<{
    attributes: Record<string, unknown> | undefined;
    listeners: Listeners | undefined;
  }>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);
  private readonly browser = isPlatformBrowser(inject(PLATFORM_ID));
  private readonly listening = new Map<string, { handler: unknown; stop: () => void }>();
  private written: Record<string, unknown> = {};

  ngOnChanges(): void {
    const element = this.element.nativeElement;
    const { attributes = {}, listeners = {} } = this.ufFallthrough();
    for (const name of Object.keys(this.written)) {
      if (!(name in attributes)) this.renderer.removeAttribute(element, name);
    }
    for (const [name, value] of Object.entries(attributes)) {
      if (value === null || value === undefined) this.renderer.removeAttribute(element, name);
      else this.renderer.setAttribute(element, name, String(value));
    }
    this.written = attributes;
    if (!this.browser) return;
    const handlers = new Map(Object.entries(listeners));
    for (const [event, { handler, stop }] of this.listening) {
      if (handlers.get(event) === handler) continue;
      stop();
      this.listening.delete(event);
    }
    for (const [event, handler] of handlers) {
      if (handler === undefined || this.listening.has(event)) continue;
      this.listening.set(event, { handler, stop: this.renderer.listen(element, event, handler) });
    }
  }

  ngOnDestroy(): void {
    for (const { stop } of this.listening.values()) stop();
  }
}
```

## Refs

A `ref` on a component that doesn't call `defineExpose` holds its root element, as Vue's `$el` does: through a chain of root components, and whatever `inheritAttrs` says. Type the ref as that element's DOM interface, by its name:

## Putting it on another element

Sometimes the root isn't the element a parent means. A text field's root is often a `<label>` around an `<input>`, and the `id`, the `placeholder` and the `focus` listener belong on the `<input>`. So a component can turn fallthrough to its root off with `defineOptions({ inheritAttrs: false })`, end its props pattern with a rest, `...rest`, and spread it whole on the element that should take it:

<!-- prettier-ignore -->
```tsx [Field.uf.tsx]
import { defineOptions } from "@uxfront/unframework";

// Turns fallthrough off and spreads what its consumer passes on its <input>, not on its root.
export default function Field({ label, ...rest }: { label: string }) {
  defineOptions({ inheritAttrs: false });
  return (
    <label class="field">
      {label} <input {...rest} name={label.toLowerCase()} />
    </label>
  );
}
```

The rest has one canonical form, and one use. It needs `defineOptions({ inheritAttrs: false })`, or it is [UF2001](/docs/reference/diagnostics#UF2001), whose safe fix adds the call. A member read like `rest.id`, a second spread, a spread in a list or a spread on a component is UF2001 too, since each target holds the rest its own way, and a member of it would mean something different on each.

```ts [field.ts]
import {
  Component,
  Directive,
  ElementRef,
  type OnChanges,
  type OnDestroy,
  type OnInit,
  PLATFORM_ID,
  Renderer2,
  inject,
  input,
  viewChild,
} from "@angular/core";

/** The scope attributes taken off each host, for the roots its component renders later. */
const scopes = new WeakMap<Element, string[]>();

/**
 * Gives a root node of its component the scope attributes the component's styled parents put on
 * its host (ADR-0063), and takes them off the host, which keeps only `display: contents`.
 */
@Directive({ selector: "[ufScope]" })
export class ScopeAttributes implements OnInit {
  readonly ufScope = input.required<HTMLElement>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);

  ngOnInit(): void {
    const host = this.ufScope();
    let names = scopes.get(host);
    if (!names) {
      names = host.getAttributeNames().filter((name) => name.startsWith("data-uf-"));
      for (const name of names) this.renderer.removeAttribute(host, name);
      scopes.set(host, names);
    }
    for (const name of names) this.renderer.setAttribute(this.element.nativeElement, name, "");
  }
}

/** A native listener of each event a consumer passes, by the event's name (ADR-0118). */
type Listeners = { [K in keyof HTMLElementEventMap]?: (event: HTMLElementEventMap[K]) => void };

/**
 * Puts what a consumer passes the component, and the component does not declare, on the element
 * that takes it (ADR-0118): the attributes, the consumer's winning over the element's own, and
 * the native listeners, which run after the element's own.
 */
@Directive({ selector: "[ufFallthrough]" })
export class Fallthrough implements OnChanges, OnDestroy {
  readonly ufFallthrough = input.required<{
    attributes: Record<string, unknown> | undefined;
    listeners: Listeners | undefined;
  }>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);
  private readonly browser = isPlatformBrowser(inject(PLATFORM_ID));
  private readonly listening = new Map<string, { handler: unknown; stop: () => void }>();
  private written: Record<string, unknown> = {};

  ngOnChanges(): void {
    const element = this.element.nativeElement;
    const { attributes = {}, listeners = {} } = this.ufFallthrough();
    for (const name of Object.keys(this.written)) {
      if (!(name in attributes)) this.renderer.removeAttribute(element, name);
    }
    for (const [name, value] of Object.entries(attributes)) {
      if (value === null || value === undefined) this.renderer.removeAttribute(element, name);
      else this.renderer.setAttribute(element, name, String(value));
    }
    this.written = attributes;
    if (!this.browser) return;
    const handlers = new Map(Object.entries(listeners));
    for (const [event, { handler, stop }] of this.listening) {
      if (handlers.get(event) === handler) continue;
      stop();
      this.listening.delete(event);
    }
    for (const [event, handler] of handlers) {
      if (handler === undefined || this.listening.has(event)) continue;
      this.listening.set(event, { handler, stop: this.renderer.listen(element, event, handler) });
    }
  }

  ngOnDestroy(): void {
    for (const { stop } of this.listening.values()) stop();
  }
}

@Component({
  selector: "uf-field",
  imports: [ScopeAttributes, Fallthrough],
  host: { "[attr.class]": "null", "[attr.style]": "'display: contents;'" },
  preserveWhitespaces: false,
  template: `
    @let label = this.label();
    <label
      class="field"
      [ufScope]="this.host"
      #ufElement
    >{{ label }}&ngsp;<input
      [ufFallthrough]="{ attributes: this.ufAttributes(), listeners: this.ufListeners() }"
      [attr.name]="label.toLowerCase()"
      [class]="this.class()"
      [style]="this.style()"
    /></label>
  `,
})
export default class Field {
  readonly label = input.required<string>();
  readonly class = input<string>();
  readonly style = input<Record<string, string | null | undefined>>();
  readonly ufAttributes = input<Record<string, unknown>>();
  readonly ufListeners = input<Listeners>();
  readonly ufElement = viewChild<ElementRef<HTMLLabelElement>>("ufElement");
  protected readonly host = inject<ElementRef<HTMLElement>>(ElementRef).nativeElement;
}
```

::

- React, Svelte, Solid and Qwik spread the rest on the `<input>` through an inline helper, `restAttributes`, which leaves out the styled parents' scope attributes, and the `<label>` keeps those through `scopeAttributes`. The `<label>` also takes the parent's `ref`, since a ref holds the root element.
- Vue binds `restAttrs($attrs)` on the `<input>` and `scopeAttrs($attrs)` on the `<label>`. Its props type declares the input's attributes behind `/* @vue-ignore */`, since vue-tsc reads them only from a root or a bare `$attrs`.
- Angular binds `[ufFallthrough]` on the `<input>`, beside the `class` and `style` inputs, and `ufElement` stays the `<label>`.
- Astro spreads `withoutScope(attrs)` on the `<input>`, and reads the input's own `name` from the props first.

## Turning it off

`defineOptions({ inheritAttrs: false })` without a rest makes a component take nothing it doesn't declare, so its root keeps a layout of its own:

<!-- prettier-ignore -->
```tsx [Field.uf.tsx]
import { defineOptions } from "@uxfront/unframework";

// Renders no class or style a consumer passes: its own layout is fixed.
export default function Field({ label }: { label: string }) {
  defineOptions({ inheritAttrs: false });
  return (
    <label class="field">
      {label} <input name={label.toLowerCase()} />
    </label>
  );
}
```

Vue writes the same `defineOptions`. The other targets type and spread nothing that falls through, and Angular's host still clears `class` and `style`. The argument is that object literal and nothing else ([UF2031](/docs/reference/diagnostics#UF2031)).

## Where nothing can fall through

A parent that passes a component something it doesn't declare has it rejected rather than dropped ([UF3045](/docs/reference/diagnostics#UF3045)) where the component has no element to take it: it turns fallthrough off and spreads no rest, or its root is a fragment, a conditional or a list, or a root component that takes nothing itself. Pass what the child declares, spread its props' rest on one of its elements, or give it one root element.

The decisions behind this page are [ADR-0054](https://github.com/uxfront-com/unframework/blob/main/docs/adrs/0054-composition-on-every-target.md), [ADR-0056](https://github.com/uxfront-com/unframework/blob/main/docs/adrs/0056-angular-hosts-in-composition.md) and [ADR-0118](https://github.com/uxfront-com/unframework/blob/main/docs/adrs/0118-attributes-listeners-and-refs-fall-through.md).
